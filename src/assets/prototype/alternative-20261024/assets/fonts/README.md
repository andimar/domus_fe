# Font per le prove tipografiche

File locali dal repository ufficiale [Google Fonts](https://github.com/google/fonts), scaricati il 24 ottobre 2026.

- [Literata](https://github.com/google/fonts/tree/main/ofl/literata): `literata.ttf`, licenza `literata-OFL.txt`.
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope): `manrope.ttf`, licenza `manrope-OFL.txt`.
- [Source Sans 3](https://github.com/google/fonts/tree/main/ofl/sourcesans3): `source-sans-3.ttf`, licenza `sourcesans3-OFL.txt`.
- [Red Hat Display](https://github.com/google/fonts/tree/main/ofl/redhatdisplay): `red-hat-display.ttf`, licenza `redhatdisplay-OFL.txt`.
- [Red Hat Text](https://github.com/google/fonts/tree/main/ofl/redhattext): `red-hat-text.ttf`, licenza `redhattext-OFL.txt`.
- [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader): `newsreader.ttf`, licenza `newsreader-OFL.txt`.

Le pagine navigabili locali servono i font dal progetto. Lato, Georgia e il marchio restano disponibili nella base. Le card conservano i caratteri originali. Il solo studio visivo MagicPath usa il CSS pubblico Google Fonts, perché l'upload del plugin non ammette TTF tra gli asset del componente.
