# Domus frontend

Frontend Twig/Tailwind indipendente. `npm install` per generare il lock iniziale, poi `npm ci` e `npm run build`. Nessun task modifica versioni, crea commit o esegue push. dist contiene template, CSS, JS e asset per il tema.

Il markup è uno scaffold tecnico: la parità grafica con Regina Lite è il prossimo lavoro. Fixture sanificate in src/data; i template usano lo stesso contratto fornito dai ViewModel PHP. Asset storici conservati in C:/dev/domus/assets-da-esaminare/vettoriali, senza importarli nella build.
